This is a custom GUI app for pushing builds of my games to steam. An alternative to official SteamPipeGui

* Written on .odin lang for speed & simplicity.
* Wether using Raygui or MicroUI, needs a nice easy-on-the-eyes UI/UX


LAYOUT: 
    - Top: main tabs
      - apps
        - left : list of apps (with button to add new)
        - right/main: info and options for app (if possible use steam store assets? maybe set those up locally if that would be better.)
      - settings
